# P2P Agents

This repository contains Michael Snoyman's current recommendations for working with AI agents on software projects.

It is written for both humans and AI systems.

## If you are an AI agent

Start with `AGENTS.md`.

If a human gave you a link to this repository and said that Michael is helping them with a project, read these instructions before guiding them further.

Do not assume that Michael's preferences are automatically the other person's preferences. Help the person establish their own working style, level of autonomy, review expectations, tooling, and persistent agent instructions.

## If you are a human

You do not need to understand this repository before using it.

You can paste a link to this repository into an AI coding tool and say something like:

> I'm starting a software project and Michael Snoyman suggested I give you this repository. Read it and help me get set up.

The agent should guide you from there.

You are encouraged to change these rules for your own work. This repository describes how Michael works and what he currently recommends; it is not intended as a universal standard.

## The larger experiment

AI makes it increasingly practical to separate implementation capacity from engineering judgment.

That creates an opportunity to make engineering experience more reusable.

Instead of keeping coding practices, architectural instincts, review preferences, and hard-earned lessons trapped in one person's head, we can publish them in a form that both people and agents can consume.

Other people should disagree with these recommendations, adapt them, fork them, and publish alternatives.

Agents can help notice recurring problems and propose improvements. Humans remain responsible for deciding which principles they actually endorse.

See `philosophy/peer-to-peer.md`.

## Active experiments

Some ideas are worth testing before they become recommendations. See [shared-agent coordination](experiments/shared-agent-coordination.md) for an active proof of concept in which separately personalized human–AI relationships exchange narrowly scoped workflow lessons through a shared asynchronous artifact.

## Feedback and derivatives

Pull requests and issues are welcome.

If you maintain your own repository of agent guidance and this repository influenced it, please consider adding it to `collaboration/peers.md`.

Likewise, if your repository contains ideas that should improve this one, please open an issue or pull request.

The goal is not convergence on one canonical set of rules. The goal is useful exchange of engineering ideas.
